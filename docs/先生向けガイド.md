## 準備するもの

| | 必要なもの | 備考 |
|---|---|---|
| 先生 | マイクの使えるPC | 字幕を使う場合は Chrome か Edge |
| 先生 | 授業で使うPDF | 複数のファイルを続けて1つのスライドにもできます |
| 生徒 | スマートフォン・タブレット・PCのいずれか | アプリのインストールもアカウントも、**名前の入力も**要りません |
| 教室（使う場合） | モニターや電子黒板につないだ端末 | テレビ内蔵のブラウザでも動きます |

アカウントを作っていない場合は、`/register` でログインIDと表示名を決めてください。
メールアドレスは要りません。

登録画面に「**登録の合言葉**」の欄が出た場合は、そのサーバでは合言葉が必要な設定になっています。
管理する方にお尋ねください。

> **ご注意** — メールアドレスをお預かりしていないため、**パスワードの再設定ができません**。
> 忘れた場合は、新しいアカウントを作り直していただくことになります。

## 1. 授業の前に — 端末を確かめる

![端末チェックの画面。役割を選ぶと、その用途に必要な項目だけを判定する](images/check-monitor.png)

初めて使う教室や、初めて使う端末では、**`/check` を開いて確認しておくと安心です**。
ログインは要りません。どの画面からでも <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> で開けます。

最初に、**その端末の役割**を選びます。役割によって必要な条件が変わるためです。

| 役割 | どんな端末か | 何を調べるか |
|---|---|---|
| **教室のモニター** | 教室に音とスライドを映す端末 | 通信・音声の形式・実際に音が出るか |
| **生徒の端末（遠隔）** | 自宅などから1人で受ける | 通信・音声の形式・実際に音が出るか |
| **生徒の端末（教室）** | 音は教室のスピーカーから聞く | 通信だけ（音は要らないため） |
| **先生の端末** | マイクとカメラで配信する | 通信・マイク・送れる形式 |

「先生の端末」を選ぶと、マイクと送信できる形式の項目が増えます。

![先生の端末を選んだときの画面。マイクと配信形式の項目が増える](images/check-teacher.png)

結果は ○ △ × で出ます。**× があると、その用途では授業に使えません。**

| 表示 | 意味 |
|---|---|
| **サーバに繋がる** | × のときは、ネットワークかフィルタリングの問題です。学校の回線でWebSocketが塞がれていることがあります |
| **ライブ音声の仕組みに対応している** | × のときは、そのブラウザでは音が鳴りません |
| **マイクを使える**（先生の端末） | × のときは、ブラウザの許可設定を確認してください |
| **テスト音を鳴らす** | 実際にスピーカーから音を出します。**イヤホンを使う場合は、挿した状態で確認してください** |

通信量も実際に測ります。ギガを使い切った生徒がいても大丈夫かどうかが、その場で分かります。

## 2. 授業を作る

![授業の一覧。ここから新しい授業を作り、終わった授業の振り返りも開く](images/dashboard.png)

1. `/dashboard` を開きます
2. 「**＋ 新しい授業を作成**」を選びます
3. 授業のタイトルを入れ、**スライドPDF**を選びます
   - 複数のファイルを選べます。**上から順につながって1つのスライドになります**
4. 作成すると、**4文字の授業コード**が表示されます（例: `KC6W`）

PDFはこの時点でサーバに保存されます。授業当日にアップロードし直す必要はありません。

## 3. 生徒に参加してもらう

授業画面の「**参加用リンク**」に、生徒へ伝えるものがまとまっています。

| 伝え方 | どうするか |
|---|---|
| 授業コード | 4文字を口頭やチャットで伝えます。生徒は `/join` で入力します |
| QRコード | 画面に表示して見せます。教室のモニターにも出せます |
| リンク | URLをそのまま送ります |

生徒がすることは、**授業コードを入れて「参加する」を押すだけ**です。
アカウントも、名前の入力も要りません。

**名前の欄は空のままで構いません。** その場合は「あおいネコ」「黄色いカワウソ」のような仮名が自動で付き、
先生の画面にはその名前で反応やコメントが届きます。
名前を入れてもらいたい場合は、口頭で「名前を入れてください」と伝えてください。

![生徒の参加画面。入れるのは授業コードだけで、名前の欄は空のままでよい](images/join.png)

参加すると、生徒の画面はこうなります。自分がどう呼ばれているかが上に出ます。

<img src="images/class.png" alt="生徒の画面。スライドの下にボタンとコメント欄がある" width="300">

授業が始まる前に参加した生徒には、「授業の開始を待っています...」と表示されます。

### 生徒がタブを閉じてしまったとき

同じ授業コードを入れ直すと、**「この端末は先ほど〇〇として参加していました」**と出ます。
「続きから参加する」を選べば、同じ生徒として戻れます（タスクの進捗もそのままです）。

<img src="images/join-resume.png" alt="同じ授業コードを入れると、前回の名前で続きから参加できる案内が出る" width="420">

「新しく参加する」を選べば別の生徒として入ります。
**共有端末で次の生徒が使う場合は、こちらを選んでください。**

## 4. 授業を始める

「**授業を開始**」を押すと、次のことが同時に始まります。

- マイクの音声配信
- 録音
- **時刻の記録**（ここからの経過時間が、すべての記録の基準になります）

画面に「**● 録音・配信中**」と出れば、届いています。

マイクが使えなかった場合は「**マイクエラー**」と表示されます。
そのときは生徒側では無音になるので、気づいたら早めに直してください。

> 授業を開始する前に書いた書き込みは、記録には残りません。
> 「授業を開始」を押してからの操作が記録の対象です。

## 5. 授業中にできること

![授業中の先生画面。左がスライドと道具、右にコメントと反応が届く](images/teach.png)

### スライドを送る

矢印のボタン、またはキーボードでページを送ります。**生徒の画面も一緒に動きます**。
授業中のページ切り替えに通信はほとんど使いません。

### 書き込む

| 道具 | 説明 |
|---|---|
| **ペン** | スライドに線を引きます。色は 朱色・緑・青・黒 から選べます |
| **文字** | 文字を書き込みます |
| **ペン・文字のサイズ** | 太さと大きさを変えます |
| **↶ 戻す**（<kbd>Ctrl</kbd>+<kbd>Z</kbd>） | 直前の書き込みを取り消します |
| **↷ 進む**（<kbd>Ctrl</kbd>+<kbd>Y</kbd>） | 取り消したものを戻します |
| **消しゴム / 全消去** | 一部だけ消す、まとめて消す |

書き込みをまとめて消すこともできます（確認の表示が出ます）。

### 白紙のページを差し込む

「**＋ 白紙を挿入**」を押すと、**いま表示しているスライドの直後に白紙ページが入ります**。
補足の説明や、その場で出た質問への板書に使えます。

**元のPDFは変更されません。** 差し込んだ白紙は、その授業だけのものです。

### 生徒の反応を見る

生徒が押したボタンとコメントが、リアルタイムで届きます。

反応が集まると「**振り返りタイム**」の通知が出ます。
通知が出る条件は2つあります。

- 同じころに**3人以上**が反応したとき（既定値）
- **15分**ごと（既定値）

通知は、**対応するまで画面に残ります**。見落としたまま授業が終わらないようにするためです。
対応したら「**対応済みにする**」を押してください。押し間違えた場合は「**✓ 対応済み（戻す）**」で戻せます。

コメントが届くと、AIが「**関連する説明**」——そのコメントが来る直前に先生が話していた内容——を探して表示します。
近い時刻に届いた複数のコメントは、1枚のカードにまとまります。
授業で扱っていない話題については、その旨が表示されます。

<img src="images/comment-insight.png" alt="コメントごとに、先生がその直前に話していた内容の要約と、周辺のボタン反応が並ぶ" width="380">

上の例では、「②の『回線を通っている時間』は、速さを上げれば減りますか」というコメントに対して、
**先生がその直前に何を話していたか**が要約されています。
ここでは「速さを上げると減るかどうかまでは説明していない」ことまで分かるので、
**次に何を補えばよいか**がその場で見えます。録音を聞き直す必要はありません。

### リアクションボタンを変える

「**リアクションボタン**」から、生徒に見せるボタンを授業ごとに変えられます。
初期値は「わかった／わからない」です。

### タスク

演習の項目を並べておくと、生徒がチェックした進み具合が棒グラフで見えます。
**5分間チェックが動いていない生徒は上に出る**ので、止まっている人に気づけます。

### アンケート

その場で設問を出せます。選択式と段階評価があります。
**集計は先生だけに見えます**（生徒には他の人の回答が見えません）。

### 音声・字幕設定

| 項目 | 説明 |
|---|---|
| **自動字幕** | 先生の発話を字幕にして生徒へ送ります。**Chrome か Edge が必要です** |
| **🔇 全員 教室から参加** | 生徒の端末の音声をまとめてOFFにします。教室で対面と併用するときに使います |
| **🔊 全員 遠隔で参加** | 生徒の端末から音を出す状態に戻します |

### 教室モニター設定

教室のモニターに映すための設定と、**先生のカメラ**の入り切りがここにあります。
カメラは、顔を見せる場合にも、手元の実演を見せる場合にも使えます。

生徒は、自分の端末で「**先生の映像を閉じる**」を選べます。通信量が気になる生徒への配慮です。
音声とスライドは閉じても続きます。

## 6. 授業を終える

「**授業を終了**」を押します。確認の表示が出ます（録音も停止します）。

生徒の画面には「授業は終了しました。おつかれさまでした。」と表示されます。

終了したあとも、記録はすべて残っています。あとからいつでも振り返れます。

## 7. 授業のあとで振り返る

![振り返り画面。録音を再生すると、その時点のスライドと書き込みが再現される](images/review.png)

`/dashboard` から授業を選ぶと、振り返りの画面が開きます。

### 同期再生

録音を再生すると、**その時点のスライド・書き込み・ポインターが自動で再現されます**。
「あのとき何を話していたか」を、当時の画面ごと見返せます。

### 3つのタブ

| タブ | 何が見えるか |
|---|---|
| **反応** | ボタン反応とコメントが時系列に並びます。それぞれの前後だけを切り出して聞けます |
| **復習動画** | つまずいた箇所を章に切り出し、生徒に公開できます |
| **スライド** | どのスライドに反応やコメントが集まったかで並び替えられます |

### 復習動画を生徒に公開する

「復習動画」タブで、**公開したい章だけを選んで**公開できます。
生徒はログインなしで見られます。

**公開したページに、生徒の名前もコメントも出ません。** 出るのは授業の内容だけです。

## 教室で対面と併用するとき

教室のモニターにつないだ端末で `/m/コード` を開くと、そこに投影されます。
ここで使うのは**モニター用の6文字のコード**で、生徒に伝える4文字の授業コードとは別のものです。
リモコンでも入力できる長さにしてあります。

このとき、**音は教室モニターの1台だけから出す**ようにしてください。
生徒の端末は「教室から参加」（音声OFF）にしておきます。
複数の端末から同じ音が出ると、反響したりハウリングしたりします。

![教室モニターの表示。操作するものは何も出さず、スライドだけを大きく映す](images/screen.png)

先生のPCに外部ディスプレイをつないでいる場合は、先生画面から「別ウィンドウで開く」を使って、
そちらへドラッグする方法もあります。

### 先生も生徒も同じ教室にいるとき

先生が生の声で話しているので、**どの端末からも音を出す必要がありません**。

1. 「音声・字幕設定」で「**🔇 全員 教室から参加**」を選びます
2. 教室モニターの音も出しません（何も操作しなければ鳴りません）

スライドと反応だけをアプリで使う形になります。
**録音は続いている**ので、文字起こし・コメント分析・授業後の振り返りはそのまま使えます。

この状態では「教室モニターが未接続です」と出ることがありますが、
モニターを使わない授業なら気にしなくて構いません。

## 困ったときは

### 音のトラブル

| 症状 | 対処 |
|---|---|
| **甲高い音が鳴り続ける** | ハウリングと思われます。先生のマイクの近くで音を出している端末を「教室から参加」に切り替えると収まります。先生画面はもともと自分の声を鳴らさないので、別の端末から音が出ていることが多いです |
| **生徒に音が届かない** | まず先生画面に「● 録音・配信中」が出ているか確認します。「マイクエラー」なら、ブラウザのマイク許可を確認してください |
| **一部の生徒だけ聞こえない** | その端末で `/check` を開きます。形式が非対応なのか、音量が0なのか、通信が塞がれているのかが分かれます |
| **音量は上げたのに聞こえない** | モニターの場合、音量は**アプリ・OS・モニター本体の3か所**にあります。入力切替も確認してください |

### 画面のトラブル

| 症状 | 対処 |
|---|---|
| **生徒の画面が真っ白** | ページを再読み込みしてください。直らない場合は `/check` で通信を確認します |
| **「再接続中...」が続く** | 通信が不安定です。学校の回線でWebSocketが塞がれている可能性もあるので、`/check` で確認できます |
| **スライドが送られない** | 先生側でページを送っているのに生徒が追従しない場合は、生徒に再読み込みしてもらってください |

### マイク・カメラのトラブル

| 症状 | 対処 |
|---|---|
| **マイクが使えない** | マイクは **HTTPS か localhost でしか使えません**（ブラウザ側の制約です）。IPアドレスを直接打ったHTTPのURLでは、許可の画面すら出ません |
| **許可を一度断ってしまった** | ブラウザのアドレスバーの左にある鍵やアイコンから、マイクの許可をやり直せます |
| **カメラが選べない** | 「教室モニター設定」の中にカメラの項目があります |

### 字幕のトラブル

| 症状 | 対処 |
|---|---|
| **字幕が出ない** | 自動字幕は **Chrome か Edge** が必要です（Safariは不安定、Firefoxは非対応） |
| **「字幕を作れません」と出る** | そのブラウザが音声認識に対応していません。Chrome か Edge で開き直してください |

## よくある質問

**Q. 生徒の顔や声は記録されますか。**
いいえ。**生徒はカメラもマイクも使いません。** システムに生徒の映像・音声を扱う機能そのものがありません。

**Q. 生徒に他の生徒の反応は見えますか。**
見えません。反応も進み具合も、先生だけに見えます。

**Q. 生徒は本名を入れる必要がありますか。**
ありません。**名前そのものを入れなくても参加できます。**
空のまま参加した生徒には「あおいネコ」のような仮名が自動で付きます。

**Q. 仮名だと、誰が質問したのか分からなくなりませんか。**
仮名は**その授業の中では変わりません**。同じ生徒からの2回目の質問は同じ名前で届くので、
「さっきの赤いキツネがまた聞いてきた」という追い方はできます。
分からなくなるのは「それが教室の誰なのか」だけです。
本名で呼びかけたい授業では、生徒に名前を入れてもらってください。

**Q. 授業の途中で参加した生徒は、それまでの内容を見られますか。**
参加した時点のスライドから表示されます。それより前の音声はライブでは戻せませんが、
復習動画を公開すれば、あとから見てもらえます。

**Q. 生徒が別のアプリを見てから戻ってきても大丈夫ですか。**
大丈夫です。通信は自動でつなぎ直し、その間に押したボタンやコメントは端末に溜めておいて、
戻ったときに**押した時刻のまま**送られます。

**Q. 生徒の回線が途切れたらどうなりますか。**
生徒がボタンやコメントを送った内容は端末に保持され、**回線が戻ったときに元の時刻で送り直されます**。
記録上の時刻はずれません。

**Q. 授業の記録はどこに残りますか。**
録音・PDF・スライドの切り替えや書き込みの記録・反応とコメントが保存されます。
授業を削除すれば消えます。

**Q. AIは何をしていますか。何が外部に送られますか。**
文字起こしと要約に使っています。外部に送られるのは**先生の音声と、その文字起こし**です。
生徒の音声は存在しませんし、生徒の個人情報も送っていません。
詳しくは [導入を検討する方へ](導入を検討する方へ.md) をご覧ください。

**Q. 何人まで参加できますか。**
人数の上限は設けていませんが、1台のサーバで動かす前提です。
学級規模から学年規模を想定しています。
